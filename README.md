# 建コン営業ナビ 公開ページ

iPhone アプリ「建コン営業ナビ」の、サポートページとプライバシーポリシーです。

| ファイル | 中身 | App Store Connect のどの欄に入れるか |
|---|---|---|
| `index.html` | サポート・よくあるお問い合わせ | サポートURL |
| `privacy.html` | プライバシーポリシー | プライバシーポリシーURL |

アイコンは画像ファイルではなく、HTMLの中に図形（SVG）として書いてあります。
読み込みで欠ける心配がなく、画面の解像度にも左右されません。
App Store Connect に出す1024pxの画像は、アプリ側の
`kenkon-navi/docs/icon-1024.png` にあります。

公開先（GitHub Pages）

- https://yoshiharu57.github.io/kenkon-navi-site/
- https://yoshiharu57.github.io/kenkon-navi-site/privacy.html

**このリポジトリは公開です。** アプリ本体（`kenkon-navi`）は非公開のままにしてください。
ここに置いてよいのは、誰に見られても困らないものだけです。

## 公開されているか確かめる

ログインしていない状態（Safari のプライベートウインドウなど）で、
上の2つのURLが開くことを確かめてください。
**片方でも開かないと、審査が止まります。**

問い合わせ先のメールアドレスにも、一度ご自身で送って、
実際に届くことを確かめてください。
